v0.2.0 release-candidate test: Install the two ZIP files above from Xbox Kodi > Settings > Add-ons > Install from zip file > rickirl91, in the order shown. Open Program add-ons > TV Streaming Lazy Wall to test details, Play and Watch Trailer; then Video add-ons > TV Streaming StreamRow to test first-position See All. Do not replace a working homepage widget until validated. This RC is not listed in the automatic-update repository index, so existing installs will not be upgraded automatically.

StreamRow test: In Xbox Kodi use Settings > Add-ons > Install from zip file > existing rickirl91 source > plugin.video.streamrow-0.1.0.zip. Then launch from Video add-ons and open Action - See All First (test). Do not replace the existing Action widget until the preview passes. This test is not yet confirmed to work on Xbox.

TV Streaming v0.2.3: With TMDb Movies installed, update the TV Streaming Catalogue add-on from this versioned ZIP. Open it and choose Connect TMDb Movies Playback (optional). This copies one player definition to the current adult Kodi profile. Confirm, then choose TMDb Movies as default movie and episode player under TMDb Helper Settings > Players. No navigation reapply is necessary. Existing navigation remains unchanged; no playback default is changed automatically.

Optional test add-ons: Install the Angelitto repository and then TMDb Movies; the Red Repo and Gratis Red are additional optional tests. The repository installers are upstream copies. Source availability and rights are the responsibility of the chosen providers and users.

Older versions remain available for rollback. The Kids profile is protected from the new playback link action.
