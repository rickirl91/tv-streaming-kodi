In Kodi choose Add-ons → Install from zip file → rickirl91 and select plugin.video.tvstreaming.catalogue-0.2.1.zip.

Then open Video add-ons → TV Streaming Catalogue & Preset, choose Install / Update Standard Arctic Fuse 3 Preset, and confirm the adult profile. A backup is created before the preset is applied.

The Kids profile should remain untouched. The v0.2.0 package is retained for rollback.
