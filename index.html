TV Streaming — Kodi Repository

Install the Kodi repository package:

repository.tvstreaming.catalogue-1.0.0.zip

Preset v0.2.0 (pilot): plugin.video.tvstreaming.catalogue-0.2.0.zip

Previous v0.1.0: plugin.video.tvstreaming.catalogue-0.1.0.zip

Kodi → File Manager → Add source: https://rickirl91.github.io/tv-streaming-kodi/, then Add-ons → Install from zip file → select the repository ZIP.

After the repository is installed, use Install from repository → TV Streaming Repository → Video add-ons → TV Streaming Catalogue & Preset.

This contains a preview build. Installing the add-on does not automatically replace your Kodi navigation; applying the preset requires confirmation and creates a backup.
