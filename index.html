Open Video add-ons → TV Streaming Catalogue & Preset → Install / Update Standard Arctic Fuse 3 Preset. The add-on backs up the adult profile shortcut files before applying. Then use Rebuild Arctic Fuse 3 Shortcuts & Widgets if the old menu is cached.
