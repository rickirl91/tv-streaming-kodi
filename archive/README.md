# TV Streaming — Archived Releases

This directory holds older direct-install ZIPs and historical test documents moved from the repository root to make current installers easy to find.

**Do not install these by default.** Use the current installation page: https://rickirl91.github.io/tv-streaming-kodi/

- `releases/`: former root-versioned installers, retained unchanged as rollback evidence
- `notes/`: superseded instructions, proofs and historical acceptance reports
- `../zips/`: retained in place, not copied or moved; older Kodi repository references can still resolve

The release contents are preserved byte-for-byte using existing Git blob IDs. Nothing has been deleted from Git history. The current Lazy Wall v0.3.1, StreamRow v0.3.0, Bulk Setup v0.1.0, Catalogue v0.2.3 and selected rollback packages remain at the root.

If an old direct URL is needed, replace the previous root filename with `archive/releases/<filename>`. Old URLs are not permanent aliases and may return 404 after the move.
