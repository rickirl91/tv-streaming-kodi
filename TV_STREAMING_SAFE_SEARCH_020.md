# Cricky Safe Search 0.2.0 RC — supported navigation
Supersedes 0.1.0 (the uninstalled XML patch). Do not apply 0.1.0. The user confirmed they had not tested/installed that candidate. If an existing tester did apply 0.1.0, restore the original skin file using that version before upgrading. 0.2.0 intentionally contains no patch/restore code, writes no skin files or settings, and has no background service.

## Phase 1: validate the native route
Install script.tvstreaming.safesearch-0.2.0-RC.zip from the existing rickirl91 source. Keep Home Personalisation 0.1.17, dismissal state, display settings, Trakt and autoplay unchanged. In Cricky open Program add-ons > TV Streaming - Cricky Safe Search (RC). It opens the native Kodi keyboard directly. Search You, select S5E1, play for 60 seconds, stop and navigate Home. Remain there for 60 seconds. Repeat with a film, test cancel and blank search. The results use the currently installed skin's native Videos view, not our final custom wall. TMDb Helper stores history in its own profile data via history=true. The launcher is Cricky-only until other profiles are implemented.

## Phase 2: supported menu integration
AF3 3.5.11's Edit menu supports Home > Menu > Submenu and custom paths/actions. Add a new Home submenu shortcut named Search; use its Path (custom action, not a plugin directory) set to RunScript(script.tvstreaming.safesearch,search), and select the magnifying-glass icon. Move to the preferred position. Exact Xbox presentation and labels need validation. A custom hub may require an additional click because hub navigation opens the hub window first, so the Home submenu is the preferred first test. If the editor permits choosing Program add-ons directly, choose this script instead of typing. Keep the old built-in Search until the new shortcut passes; then disable it using Edit menu > Search > disable. Do not repurpose an existing catalogue hub or reset the skin. Re-enable original Search and remove the custom shortcut for rollback. Native skin settings generally persist across compatible updates, not guaranteed across major migrations.

## Phase 3: visual polish
After native Search playback and return Home pass, evaluate the native poster/landscape view. If needed, extend the existing Lazy Wall in a separately tested version, using its own window resources, closing search UI before handoff to native playback. Do not modify installed skin XML or depend on internal multisearch. No custom wall is included in this release.

Source contract: TMDb Helper resources/tmdbhelper/lib/items/directories/tmdb/lists_search.py in 6.22.7 handles both -> multi and explicit history=true. AF3 3.5.11 Dialog_DialogShortcuts.xml includes supported custom action, label and icon, and Search toggle. The original built-in magnifying glass is fixed, so the replacement may not occupy exactly the same position.
